## 简介（一句话）

## 关于游戏

《蚀线》是一款黑白纸雕风格的光影解谜游戏。你将穿过一座悬浮在黑暗中的纸城：没有灯的地方会坠落，被两盏灯同时照亮的地方同样危险，只有恰好被一盏灯照到的“蚀线”能够承重。

游戏的每个机关都围绕同一条规则展开。你可以转动路灯、推开遮光箱、拾起提灯，或把自己的影子钉在纸面上，让它冻结成桥、压住机关，甚至替你走进暗处。十个短关卡会逐步引入遮挡、折光、移动灯塔和日轮终局；每次操作都会让整座纸城重新显影。

故事没有姓名和对白。你是一个被白昼与黑夜同时删去的人，只能沿着它们留下的交界前进。随着旅程推进，剪影会逐渐长出纸刻的细节，城市也从黎明、正午走到灯塔之夜，最终收束成通往日轮的一条细线。

支持键鼠、触屏与标准手柄，带有自动检查点、章节选择、提示、减少闪白和跨会话进度。全程免费，无广告、无体力和强制评分。

## 操作说明

**键鼠**：WASD / 方向键移动；E 互动；空格钉住或收回影子；Q / C 切换视角；F 近距离观察；H 查看目标；R 重开本关；Esc 暂停。

**手柄**：左摇杆移动；A 互动；B 钉住或收回影子；肩键切换视角；菜单键暂停。

**触屏**：左侧虚拟摇杆移动；靠近灯、纸闸、纸箱或提灯后点击互动；右下角影子按钮钉住或收回影子；暂停按钮打开菜单。点击路灯后可转向，按住灯头拖动可连续调光。

**生存规则**：纯黑是影渊，过曝白是日蚀白，两者都会让角色碎裂并回到最近检查点；冷白单光区域才是安全的蚀线。
